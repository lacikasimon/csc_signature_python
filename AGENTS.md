# Project Instructions

- A munka vegen, ha kodot vagy dokumentaciot modositottal, futtasd a relevans ellenorzeseket.
- Ezutan keszits git commitot a valtozasokbol, majd futtasd a `git push` parancsot az aktualis branchre, kiveve ha a felhasznalo kifejezetten mast ker.
- Push elott ellenorizd a `git status --short --branch` kimenetet. Ne hagyj szandekosan commitolatlan, a feladathoz tartozo valtozast.
- Ha a push halozati vagy jogosultsagi okbol nem sikerul, mondd el roviden a felhasznalonak, es add meg a pontos parancsot, amit futtatni kell.
